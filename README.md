# Kimemiah Family App: Plan

Our own web app for the Kimemiah household, from what's in the kitchen to who's doing the market run. It installs from one link onto everyone's phone, works offline and syncs when there's signal.

**Status:** design agreed (council review, 21 Oct 2026). Nothing is built yet.

## The idea in one line

Volunteer, don't assign. Jobs go on a shared board, anyone picks them up, and the app makes it easy to see what needs doing and to thank whoever did it.
