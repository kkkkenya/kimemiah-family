# Kimemiah Family App: Plan

A shared web app for the Kimemiah household to keep the house in order, from what's in the kitchen to who's doing the market run. It opens from one private link on everyone's phone. Nothing to install.

**Status:** planning. Nothing is built yet.

## The idea in one line

Volunteer, don't assign. Jobs go on a shared board, anyone picks them up, and the app makes it easy to see what needs doing and to thank whoever did it.
